# Gaurav Alfred Gamre — Portfolio

Premium static React + Vite portfolio for Gaurav Alfred Gamre.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Resume

Place the real resume PDF at:

`public/Gaurav-Gamre-Resume.pdf`

The existing **Download Resume** button will then work automatically.

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository into Vercel.
3. Select Vite if prompted.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Deploy to Netlify

1. Connect the GitHub repository.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Deploy.

No backend, database, authentication or environment variables are required.
